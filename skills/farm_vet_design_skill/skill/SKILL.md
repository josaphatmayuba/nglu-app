# Skill — Analyse et redesign application ferme, élevage et vétérinaire

## But du skill
Ce skill sert à analyser, améliorer et concevoir une application de gestion d'élevage, ferme et vétérinaire.

Il doit aider à transformer une application existante en produit professionnel vendable aux :

- fermiers ;
- entreprises agricoles ;
- vétérinaires ;
- coopératives ;
- gestionnaires de fermes ;
- ONG agricoles ;
- superviseurs terrain.

---

## Quand utiliser ce skill
Utiliser ce skill quand l'utilisateur demande :

- d'analyser une application ferme / élevage ;
- d'améliorer le design d'une application agricole ;
- de créer un prompt pour une application d'élevage ;
- de comparer son application aux besoins du marché ;
- d'ajouter des modules vétérinaires ;
- de créer une application pour porcs, bovins, chèvres, moutons, volailles ;
- de créer un dashboard ferme ;
- de gérer santé animale, reproduction, mortalité, stock, bâtiments, rentabilité.

---

## Principes de réponse
Toujours répondre avec une vision produit professionnelle.

Ne pas seulement dire “ajoute un bouton”. Toujours penser :

1. utilisateur terrain ;
2. vétérinaire ;
3. gestionnaire ;
4. entreprise ;
5. rentabilité ;
6. données ;
7. rapports ;
8. mobile-first.

---

## Analyse du design existant
Quand un projet est fourni, vérifier :

- clarté de navigation ;
- dashboard ;
- responsive mobile ;
- PWA ;
- accès rapide ;
- lisibilité terrain ;
- taille des boutons ;
- organisation par espèce ;
- fiche animal ;
- modules santé ;
- modules vétérinaires ;
- stock ;
- finances ;
- rapports ;
- alertes ;
- rôles utilisateurs.

Donner une note séparée pour :

- design visuel ;
- expérience fermier ;
- expérience vétérinaire ;
- expérience gestionnaire ;
- potentiel commercial.

## Design recommandé
Toujours recommander un design :

- mobile-first ;
- PWA ;
- gros boutons ;
- cartes KPI ;
- icônes agricoles ;
- couleurs santé ;
- bouton flottant d'action rapide ;
- menu bas sur mobile ;
- sidebar sur desktop ;
- fiches simples ;
- tableaux seulement pour les rapports.

Couleurs :

- vert pour santé / agriculture ;
- rouge pour urgence ;
- orange pour attention ;
- bleu pour information ;
- brun doux pour identité ferme ;
- gris clair pour fond.

---

## Modes utilisateurs
Toujours proposer 3 modes.

### Mode Éleveur
Simple, rapide, terrain.

### Mode Vétérinaire
Clinique, diagnostic, ordonnance, laboratoire.

### Mode Gestionnaire
Finances, RH, rentabilité, rapports.

---

## IA vétérinaire
Quand l'utilisateur veut différencier son produit, proposer un assistant IA vétérinaire.

L'IA doit :

- analyser symptômes ;
- proposer hypothèses ;
- suggérer examens ;
- évaluer urgence ;
- rappeler qu'elle ne remplace pas le vétérinaire ;
- aider à générer un rapport.

Ne jamais présenter l'IA comme un diagnostic médical définitif.

---

## Format de livrable recommandé
Quand l'utilisateur demande un prompt, produire :

1. contexte ;
2. objectif ;
3. problèmes du design actuel ;
4. modules à ajouter ;
5. flux utilisateur ;
6. exigences UI/UX ;
7. exigences techniques ;
8. critères d'acceptation ;
9. résultat attendu.

---

## Critères d'acceptation
Un bon redesign doit permettre :

- créer un animal en moins de 30 secondes ;
- enregistrer une vaccination rapidement ;
- déclarer un décès rapidement ;
- consulter l'historique santé d'un animal ;
- générer un rapport vétérinaire ;
- calculer le profit d'un animal ou lot ;
- voir les alertes du jour ;
- fonctionner sur téléphone ;
- fonctionner hors ligne ;
- synchroniser les données.

---

## Réponse courte recommandée

1. dossier vétérinaire complet ;
2. mortalité ;
3. rentabilité par animal ;
4. bâtiments ;
5. actions rapides mobile ;
6. IA vétérinaire ;
7. RH et tâches ;
8. rapports PDF/Excel.
