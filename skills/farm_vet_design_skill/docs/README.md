# Pack design ferme + vétérinaire

Ce ZIP contient :

- `prompts/PROMPT_COMPLET_DESIGN_FERME_VETERINAIRE.md` : prompt complet à donner à un agent IA ou développeur.
- `skill/SKILL.md` : skill réutilisable pour analyser et améliorer les applications ferme / élevage / vétérinaire.

## Utilisation rapide

1. Dépose le dossier `skill` dans ton système de skills.
2. Utilise le prompt complet pour demander à un agent de modifier ton application.
3. Adapte les modules selon ton projet existant.

Objectif : créer une application vendable aux fermes, entreprises agricoles et vétérinaires.
