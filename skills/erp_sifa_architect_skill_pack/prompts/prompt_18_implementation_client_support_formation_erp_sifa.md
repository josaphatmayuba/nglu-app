# PROMPT 18 — IMPLÉMENTATION CLIENT, FORMATION, SUPPORT ET ACCOMPAGNEMENT ERP/SIFA

## Objectif

Ce prompt sert à concevoir la méthode d’implémentation client de l’ERP/SIFA.

Un ERP ne se vend pas seulement avec du code.  
Il faut savoir :

```text
installer
configurer
former
accompagner
supporter
corriger
améliorer
```

Ce prompt aide à préparer une méthodologie professionnelle pour déployer le système chez un client réel.

---

# 1. Mission principale

Produire un plan complet pour :

1. onboarding client
2. analyse besoin client
3. configuration initiale
4. migration données
5. formation utilisateurs
6. support démarrage
7. suivi pilote
8. gestion incidents
9. amélioration continue
10. satisfaction client

---
