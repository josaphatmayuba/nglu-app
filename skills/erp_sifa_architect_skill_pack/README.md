# ERP/SIFA Architect Skill Pack

Ce dossier contient un pack prêt à intégrer dans ton projet pour guider un agent IA, un développeur ou une équipe technique.

## Contenu

```text
SKILL.md
prompts/
docs/
```

## Fichier principal

```text
SKILL.md
```

C’est le fichier à donner comme instruction principale à ton agent IA.

Le dossier `prompts/` contient les 20 prompts ERP/SIFA :

```text
01. Audit et transformation globale
02. Audit réel backend

05. Commercialisation et sécurité

15. Intégrations et API
```

## Comment l’utiliser dans ton projet

1. Dézippe ce dossier dans ton projet.
2. Mets-le par exemple ici :

```text
/docs/erp-sifa-skill/
```

ou :

```text
/ai/skills/erp-sifa-architect/
```

3. Donne cette instruction à ton agent IA :

```text
Lis le fichier SKILL.md et utilise les fichiers dans /prompts comme référence.
Ta mission est d’analyser mon projet ERP/SIFA existant et de commencer par le Prompt 2.
```

## Ordre recommandé

```text
Prompt 2 → Audit réel
Prompt 9 → Backlog
Prompt 3 → Plan technique
Prompt 13 → Migration
Prompt 14 → Gouvernance
Prompt 4 → Frontend UX
Prompt 8 → Démo
Prompt 10 → Roadmap
```

Transformer ton projet existant en :

```text
ERP/SIFA Enterprise mature, vendable, auditable et évolutif.
```
