# Stalwart Mail Server

Docker deployment for the self-hosted mail server used by `ongdngolu.org`.

## Server Layout

```txt
/opt/nglu-app        CRM / website
/opt/stalwart-mail   Stalwart Mail Server
```

The mail service is intentionally separated from the CRM compose stack.

## First Deploy

1. Copy this directory to the server:

```bash
sudo mkdir -p /opt/stalwart-mail
sudo cp docker-compose.yml .env.example /opt/stalwart-mail/
cd /opt/stalwart-mail
sudo cp .env.example .env
sudo nano .env
```

2. Change `STALWART_RECOVERY_ADMIN` to a strong password.

3. Start:

```bash
docker compose up -d
docker logs stalwart-mail --tail 80
```

4. Open the setup wizard from the server, or through an SSH tunnel:

```txt
http://127.0.0.1:8088/admin
```

Example SSH tunnel from your workstation:

```bash
ssh -L 8088:127.0.0.1:8088 ubuntu@SERVER_IP
```

## Lightsail DNS

Add these starter records, then add DKIM/MTA-STS records generated by Stalwart.

```txt
A     mail    SERVER_STATIC_IP
MX    @       priority 10 -> mail.ongdngolu.org
TXT   @       v=spf1 mx ~all
TXT   _dmarc  v=DMARC1; p=none; rua=mailto:postmaster@ongdngolu.org
```

## Lightsail Firewall

Open publicly:

```txt
25/tcp    SMTP inbound
465/tcp   SMTPS
587/tcp   SMTP submission
993/tcp   IMAPS
```

Keep public access to `8088` closed. The admin listener should stay bound to `127.0.0.1`; use the SSH tunnel above for direct access, or put it behind HTTPS plus VPN/IP allowlisting if browser admin access is required.

## CRM SMTP Settings

After creating `noreply@ongdngolu.org` in Stalwart:

```env
SMTP_HOST=mail.ongdngolu.org
SMTP_PORT=587
SMTP_USER=noreply@ongdngolu.org
SMTP_PASS=<mailbox-password>
SMTP_FROM=noreply@ongdngolu.org
```

## Important

AWS/Lightsail may restrict outbound port 25. If outbound delivery fails, request removal of the email sending limitation from AWS or use an external SMTP relay for outbound messages.
